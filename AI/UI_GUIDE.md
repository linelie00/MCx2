# UI_GUIDE.md

## UI 콘셉트

이 프로젝트의 UI는 자캐커플 "미하티"의 세계관과 감성을 보여주는 개인 기록 보관소를 목표로 한다.

핵심 콘셉트:

- 양피지
- 낡은 책
- 중세풍 기록 보관소
- 오래된 문서
- 차분한 감성
- 캐릭터 고유 색상
- 조용한 서사

전체적으로 사용자가 오래된 책을 펼치거나, 기록 보관소에서 캐릭터와 세계관 문서를 열람하는 느낌을 받아야 한다.

## 디자인 방향

### 유지할 방향

- 현재 디자인의 기본 구조와 분위기는 최대한 유지한다.
- 기존 Home, World, Character 페이지는 완전히 새로 갈아엎기보다 개선하는 방향으로 수정한다.
- 캐릭터 고유 색상은 중요한 시각 요소로 유지한다.
- 페이지별 개성은 살리되, 전체적으로 같은 세계 안에 있는 느낌을 준다.

### 강화할 방향

- 양피지 질감
- 낡은 종이 배경
- 책의 장 또는 문서 카드 느낌
- 잔잔한 테두리 장식
- 고풍스러운 제목 스타일
- 차분한 색감
- 기록물 같은 정보 배치

### 피해야 할 방향

- 지나치게 현대적인 대시보드 UI
- 너무 밝고 깨끗한 흰색 위주의 UI
- 원색 중심의 강한 색감
- 과도한 네온 효과
- 과한 애니메이션
- 복잡한 인터랙션
- 너무 많은 장식으로 가독성을 해치는 구성

## 컬러 방향

### 기본 색상

추천 기본 색상 계열:

```txt
Background:
- 짙은 갈색
- 어두운 밤색
- 먹색에 가까운 브라운

Surface:
- 양피지색
- 바랜 베이지
- 낡은 종이색

Text:
- 짙은 갈색
- 잉크색
- 어두운 회갈색

Border:
- 바랜 금색
- 브론즈
- 짙은 갈색

Accent:
- 캐릭터 고유 색상
```

예시 팔레트:

```css
:root {
  --color-bg: #1f1712;
  --color-bg-soft: #2b211a;

  --color-parchment: #d8c39a;
  --color-parchment-light: #ead9b8;
  --color-parchment-dark: #b99b68;

  --color-ink: #2a1c14;
  --color-ink-soft: #5a4636;

  --color-border: #8a6a3f;
  --color-gold-muted: #b3925a;

  --color-shadow: rgba(0, 0, 0, 0.35);
}
```

## 캐릭터 고유 색상 사용 규칙

캐릭터 고유 색상은 다음 위치에 사용한다.

- 캐릭터 이름 강조
- 캐릭터 카드 테두리
- 캐릭터 배지
- 인용구 왼쪽 라인
- Character 페이지 포인트 색상
- Gallery 필터
- Story 관련 캐릭터 표시

주의 사항:

- 캐릭터 색상을 페이지 전체 배경에 과하게 사용하지 않는다.
- 기본 양피지/중세풍 톤과 어울리도록 채도를 낮춰 사용한다.
- 강한 원색은 필요하면 어둡게 보정해서 사용한다.

예시:

```js
{
  id: "character-a",
  name: "캐릭터 이름",
  color: "#7f4f3a",
  subColor: "#c7a27b"
}
```

## 폰트 방향

폰트는 가독성을 우선한다.

추천 방향:

- 제목: 고풍스럽고 장식적인 느낌
- 본문: 읽기 쉬운 세리프 또는 명확한 산세리프
- 한글 가독성이 떨어지는 폰트는 피한다

사용 가능 방향:

```txt
Title:
- 세리프 계열
- 명조 계열
- 중세풍이 느껴지는 장식적 폰트

Body:
- 읽기 쉬운 본문용 폰트
- 너무 얇지 않은 글꼴
```

주의:

- 장식 폰트는 제목이나 짧은 문구에만 사용한다.
- 긴 본문에는 반드시 읽기 쉬운 폰트를 사용한다.

## 레이아웃 원칙

### 전체 레이아웃

- 중앙 정렬 기반
- 넓은 여백 사용
- 한 화면에 너무 많은 정보를 넣지 않음
- 섹션 간 간격을 충분히 둠
- 카드나 문서 단위로 정보 분리

### 페이지 구조 예시

```txt
Page
  ├─ Page Header
  ├─ Intro Quote
  ├─ Main Content Section
  ├─ Related Content
  └─ Navigation Link
```

## 공통 컴포넌트 스타일

### ParchmentCard

양피지 느낌의 기본 카드이다.

사용 위치:

- Character 카드
- World 설명 카드
- Story 카드
- Gallery 이미지 설명
- Playlist 곡 설명

스타일 방향:

- 바랜 종이색 배경
- 어두운 잉크색 텍스트
- 얇은 브라운/골드 테두리
- 약한 그림자
- 모서리는 살짝 둥글게
- 필요 시 배경 질감 이미지 사용

---

### SectionTitle

각 섹션의 제목이다.

스타일 방향:

- 고풍스러운 글꼴
- 얇은 장식 라인
- 작은 부제목 가능
- 너무 크거나 화려하지 않게

예시 구성:

```txt
[장식 라인] World Record [장식 라인]
작은 설명 문구
```

---

### QuoteBox

캐릭터나 세계관의 대표 문장을 보여주는 컴포넌트이다.

스타일 방향:

- 왼쪽에 캐릭터 고유 색상 라인
- 양피지 배경
- 기울임 또는 작은 장식
- 출처 또는 캐릭터 이름 표시 가능

---

### Navigation

전체 페이지 이동을 담당한다.

스타일 방향:

- 책갈피
- 기록 보관소 메뉴
- 오래된 문서의 목차
- 상단 또는 사이드 메뉴 가능

메뉴 항목:

- Home
- World
- Character
- Story
- Gallery
- Playlist

현재 위치는 은은하게 강조한다.

## 페이지별 UI 방향

### Home

목표:

- 웹페이지의 첫인상 형성
- 미하티의 분위기 전달
- 각 페이지로 이동하는 입구 역할

UI 요소:

- 대표 타이틀
- 짧은 소개 문구
- 인용구
- 페이지 이동 카드
- 배경 장식

표현 방향:

- 낡은 책의 표지 또는 첫 장
- 기록 보관소의 입구
- 조용하고 신비로운 분위기

---

### World

목표:

- 세계관 설정을 기록물처럼 보여준다.

UI 요소:

- 세계관 섹션 카드
- 설정 문서
- 연표
- 장소 또는 개념별 카드

표현 방향:

- 오래된 문서철
- 역사 기록
- 세계관 설정집

---

### Character

목표:

- 캐릭터의 개성과 관계성을 보여준다.

UI 요소:

- 캐릭터 프로필 카드
- 캐릭터 이미지
- 대표 문구
- 성격 키워드
- 관계 설명
- 캐릭터 고유 색상

표현 방향:

- 인물 기록서
- 초상화와 프로필 문서
- 캐릭터별 고유 색이 들어간 문서 카드

---

### Story

목표:

- 미하티의 이야기를 읽기 좋은 형태로 제공한다.

UI 요소:

- 이야기 목록
- 에피소드 카드
- 상세 보기
- 관련 캐릭터
- 태그

표현 방향:

- 책의 장
- 오래된 일지
- 기록된 사건 목록

---

### Gallery

목표:

- 이미지를 감성적으로 감상할 수 있게 한다.

UI 요소:

- 이미지 그리드
- 이미지 프레임
- 이미지 확대 모달
- 제목/설명
- 태그/필터

표현 방향:

- 낡은 액자
- 보관된 그림
- 기록 보관소의 이미지 자료

---

### Playlist

목표:

- 미하티와 어울리는 음악을 정리하고 감상할 수 있게 한다.

UI 요소:

- 곡 목록
- 곡 설명
- YouTube 영상
- 캐릭터/스토리 연결
- 플레이리스트 관리

표현 방향:

- 음악 기록장
- 오래된 악보
- 감정의 기록

## 반응형 기준

모바일에서도 감성은 유지하되 가독성을 우선한다.

### Desktop

- 넓은 여백
- 2열 또는 3열 카드 배치 가능
- 이미지와 텍스트를 나란히 배치 가능

### Tablet

- 2열 카드 가능
- 본문 폭 제한
- 메뉴 간격 조정

### Mobile

- 1열 배치
- 카드 너비 100%
- 텍스트 크기 조정
- 메뉴는 간단하게 표시
- 이미지 모달은 화면 크기에 맞게 조정

## 애니메이션 원칙

애니메이션은 최소한으로 사용한다.

사용 가능한 애니메이션:

- 부드러운 fade-in
- hover 시 약한 그림자 변화
- 카드가 살짝 떠오르는 효과
- 페이지 전환 시 은은한 등장

피해야 할 애니메이션:

- 빠른 회전
- 과한 확대
- 번쩍이는 효과
- 너무 많은 요소가 동시에 움직이는 효과

## 이미지 스타일

이미지는 다음 방식으로 표현한다.

- 얇은 액자 느낌의 테두리
- 바랜 색감과 어울리는 배경
- 이미지 주변에 충분한 여백
- 설명 텍스트는 작은 기록 문구처럼 배치

Gallery 이미지의 경우:

- 기본은 그리드
- 클릭 시 모달
- 모달 배경은 어둡게
- 이미지 설명은 양피지 카드로 표시

## 버튼 스타일

버튼은 현대적인 CTA 버튼보다는 책갈피나 문서 버튼 같은 느낌을 준다.

스타일 방향:

- 브라운/골드 계열 테두리
- 양피지 배경
- hover 시 살짝 어두워짐
- 텍스트는 짙은 잉크색

버튼 종류:

- Primary: 주요 이동
- Secondary: 보조 이동
- Text: 작은 링크

## 접근성 및 가독성

- 배경과 텍스트 대비를 충분히 확보한다.
- 긴 본문은 줄 간격을 넉넉하게 둔다.
- 장식 요소가 텍스트를 가리지 않게 한다.
- 모바일에서 글자가 너무 작아지지 않게 한다.
- 이미지에는 가능한 경우 alt 텍스트를 작성한다.

## 전체 UI 완료 기준

UI가 완료되었다고 판단하는 기준은 다음과 같다.

- 모든 페이지가 같은 세계관 안에 있는 것처럼 보인다.
- Home에서 전체 분위기를 바로 이해할 수 있다.
- Character 페이지에서 캐릭터 고유 색상과 개성이 드러난다.
- World와 Story는 기록물처럼 읽힌다.
- Gallery는 이미지 감상에 집중할 수 있다.
- Playlist는 음악과 서사가 연결된 느낌을 준다.
- 모바일에서도 레이아웃이 깨지지 않는다.
- 과하지 않지만 분명한 중세풍/양피지/기록 보관소 느낌이 난다.
