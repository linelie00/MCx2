# MIHEARTI 디스코드 봇

사이트(`client` + `server`)에 연결되는 디스코드 봇. 둘만 쓰는 비공개 서버용.

데이터는 **전부 사이트 API(HTTP)를 통해서만** 읽고 쓴다.
`server/src/data/*.json` 을 직접 열면 안 된다 — 그 스토어들은 파일 전체를 통째로 덮어쓰는
방식이라 락이 없고, 두 프로세스가 같이 쓰면 갱신이 유실된다.

## 필요한 것

- **Node 20 이상.** 내장 `fetch`/`FormData` 를 그대로 쓴다.
- 네이티브 빌드가 필요한 의존성은 없다. `npm install` 이면 끝이다.

## 로컬 실행

```bash
cd bot
cp .env.example .env      # 값을 채운다
npm install
npm run register          # 슬래시 명령 등록 (명령 이름/옵션을 바꿨을 때만)
npm run dev
```

`.env` 에 넣을 값은 `.env.example` 의 주석을 참고할 것. 토큰과 패스코드가 들어가므로
**절대 커밋하지 않는다**(`.gitignore` 에 있음).

## Railway 배포

기존 프로젝트에 **서비스를 하나 더** 만든다. 서버와 같은 레포를 쓰되 폴더만 다르다.

1. New Service → GitHub Repo → 같은 레포
2. Settings → **Root Directory = `bot`**
3. Settings → **Watch Paths = `/bot/**`**
4. **기존 `server` 서비스에도 Watch Paths = `/server/**` 를 추가한다.**
   안 하면 봇만 고쳐도 API 가 같이 재배포된다.
5. Variables 에 `.env.example` 의 값들
   - `MIHEARTI_API_BASE` 는 `server` 서비스의 공개 도메인
   - `OWNER_*_KEY` 는 `server` 와 같은 값
6. 볼륨·공개 도메인·PORT **모두 불필요**. 워커 서비스로 둔다.

> Root Directory 를 `bot` 으로 두면 Railway 는 그 폴더만 내려받는다.
> 런타임에 `../client` 는 존재하지 않으므로, 캐릭터·대사 데이터는 생성해서
> `bot/data/` 에 커밋해 둔다(`npm run build-content`).

## 요트 다이스

한국식 12칸 룰이다. 갈리는 지점은 `src/yacht/rules.js` 머리말에 못 박아 뒀다
(포카드·풀하우스는 주사위 5개의 합, 야찌는 풀하우스에도 적을 수 있다).

판은 **스레드에서** 돈다. `/요트 시작` 이 스레드를 하나 파고 그 안에서 진행하므로,
주사위와 NPC 대사가 오가도 원래 채널이 묻히지 않는다. 스레드를 못 만드는 채널이면
(권한이 없거나 이미 스레드 안이면) 그 채널에서 그대로 진행한다.

NPC 가 말을 하고 나면 판이 대사에 밀려 올라가므로, NPC 차례가 끝날 때마다 판을
맨 아래에 **새로 띄운다.** 사람이 자기 턴을 두는 동안은 있는 자리에서 고치기만 한다.

굴릴 때마다 결과가 채팅에 한 줄씩 남는다 — 사람이든 NPC 든.

```
🎲 겨울 2번째 — [5️⃣] 3️⃣ [5️⃣] 1️⃣ 6️⃣
```

`[ ]` 안이 남겨 둔 주사위다. 남긴 것을 따로 한 번 더 적으면 줄만 길어지고 어느 자리가
남은 것인지는 여전히 안 보여서, 결과 안에서 구분해 그린다.

판만 보면 무엇을 쥐고 무엇을 다시 굴렸는지가 순식간에 지나가고, 판을 새로 띄우면
앞 굴림도 같이 사라진다. 채팅에 남겨 두면 턴을 되짚을 수 있다.

주사위 눈은 키캡 숫자 이모지(1️⃣~6️⃣)로 그린다. 유니코드 주사위 문자(⚀⚁⚂)를 쓰다가
바꿨다 — 렌더는 되지만 본문 글자 크기의 흑백이라 눈이 몇인지 알아보기 어려웠다.

**진짜 주사위 그림을 쓰고 싶으면** 서버 설정 > 이모지에 그림 6장을 `dice1` ~ `dice6`
이름으로 올리면 된다. 봇이 부팅할 때 이름으로 찾아 자동으로 갈아 끼운다(코드 수정
불필요). 하나라도 없으면 그 눈만 키캡으로 남는다.

**남긴 주사위를 색으로 구분하려면** 다른 색 그림 6장을 `dice1k` ~ `dice6k` 로 더
올린다. 그러면 `[ ]` 대신 그 색으로 그린다. 이모지에는 굵게·색 같은 마크다운이 안
먹어서, 표준 이모지만으로는 색을 달리할 방법이 없다.

그림은 만들어 쓰면 된다. 사이트 톤(양피지 / 초록)에 맞춘 12장이 나온다.

```bash
node bot/scripts/make-dice-emoji.mjs
```

`/요트 시작` 으로 자리를 열고 `참가` 나 `미겔 부르기` / `마티암 부르기` 로 채운다.
`/요트 시작 상대:마티암` 처럼 상대를 지정하면 대기실을 건너뛰고 바로 시작한다.
NPC 는 성향대로 둔다 — 미겔은 크게 노리고 마티암은 안전하게 간다. `/요트 판` 은 판이 위로 밀려났을 때
다시 띄우고, `/요트 그만` 은 접는다. 10분 동안 아무도 안 누르면 자동으로 접힌다.

판은 **메모리에만** 있다. 봇이 재시작되면 진행 중이던 판이 사라지고, 남아 있던 버튼을
누르면 그렇게 안내한 뒤 버튼이 걷힌다.

NPC 는 **말할 만한 순간에만** 한 줄 한다 — 야찌, 어쩔 수 없는 0점, 보너스 확보나 무산,
역전, 그리고 판이 끝났을 때. 매 턴 떠들면 성격이 아니라 소음이고 Gemini 한도도 금방 닳는다.
대사가 안 나와도 판은 그대로 돌아간다(`GEMINI_API_KEY` 가 없어도 게임은 된다).

대사는 캐입과 **같은** Gemini 한도를 나눠 쓴다. 구글 쪽 한도가 하나뿐이라 카운터를 따로
두면 실제 한도를 넘겨 사람이 쓰는 `/캐입` 이 429 를 맞는다. 대신 요트는 분당 한도의 60%
까지만 써서 사람 몫을 남긴다. 대사가 자주 빠지면 `GEMINI_RPM` 을 올린다.

NPC 성향을 손보려면 `src/yacht/ai.js` 의 `STYLES` 를 고치고 다음으로 확인한다.

```bash
node bot/scripts/simulate-yacht.mjs 300
```

## 음성 재생을 뺀 이유

봇이 음성 채널에서 직접 트는 기능이 한때 있었지만 뺐다.

- 유튜브가 **데이터센터 IP 를 차단**한다. 같은 쿠키로 가정용 IP 에서는 되는데
  Railway 에서는 "Sign in to confirm you're not a bot" 으로 막혔다.
  쿠키를 넣으면 잠깐 되다가 40분쯤 뒤 다시 막혔고, PO 토큰도 이미 막힌 IP 는 못 살린다.
- 추출 도구(yt-dlp)를 상용 호스트에 두는 것 자체가 **약관에 걸릴 소지**가 있다.

대신 `/플리 듣기` 가 사이트 링크와 유튜브 링크(전곡 임시 재생목록)를 준다.
되살리고 싶으면 이 기능을 뺀 커밋을 revert 하면 된다 — 가정용 IP 에서는 잘 동작했다.

## 데이터 재생성

캐릭터·대사·세계관은 `client/src/Data/` 가 원본이고, 봇은 생성된 JSON 만 읽는다.
원본을 고쳤으면 **레포 루트에서** 다시 생성하고 커밋한다.

```bash
node bot/scripts/build-content.mjs
```

`bot/data/quotes.json`(명대사)만 예외로 사람이 직접 편집하는 파일이고, 생성 스크립트가 덮지 않는다.

## 블랙잭

카지노 "bard". 요트와 같은 배관(스레드, 버튼, 방치 정리)을 쓴다.
룰은 `src/blackjack/rules.js` 머리말에 전부 못 박아 뒀다 — 6덱 S17, 블랙잭 3:2,
DAS, 레이트 서렌더, 딜러 피크, 베팅은 50의 배수.

딜러는 기본이 **미겔**이고, 미겔을 플레이어로 앉히면 **npc** 가 딜러를 맡는다.
누가 딜러인지는 `start()` 에서 얼린다 — 판 도중에 바뀌면 혼란스럽다.

칩은 **서버에 영구 저장된다**(`src/casino/wallet.js`). 블랙잭·홀덤이 한 잔액을 나눠 쓰고,
한 판에 들고 앉는 칩은 **판돈 등급**이 정한다 — `/블랙잭 시작 판돈:` · `/홀덤 시작 판돈:` 으로
마이크로·로우·미들·하이 중에 고르고, 안 고르면 로우(블라인드 10/20 · 최대 1000칩)다.
모자라면 `/출첵` 으로 하루 한 번 채운다.
미겔·마티암도 손님으로 앉을 때는 자기 돈을 쓴다 — 딜러일 때는 안 쓴다(딜러는 자리가 아니다).
설계와 함정은 [docs/CASINO_CHIPS.md](../docs/CASINO_CHIPS.md) 에 적어 뒀다.

```bash
cd bot && npm run check-wallet    # 장부 ↔ 서버가 어긋나지 않는지
```

규칙과 NPC 성향은 디스코드 없이 검증한다.

```bash
node bot/scripts/simulate-blackjack.mjs 50000
```

**칩 총합 보존**이 이 시뮬레이터의 존재 이유다 — 증감이 (돌아온 것 − 건 것) 과 맞는지
매 핸드 확인한다. Split·Double·Insurance 정산이 제일 틀리기 쉽다.

### 카드 그림

카드는 **앱 이모지**로 올린다. 서버 이모지는 무료 50칸이라 53장이 안 들어가지만
앱 이모지는 앱당 2000개이고 서버 슬롯을 안 먹는다.

```bash
node bot/scripts/make-card-emoji.mjs --sheet cards.png   # 올리기 전에 눈으로 확인
node bot/scripts/make-card-emoji.mjs                     # 그려서 API 로 바로 올린다
```

작게 보일 때 읽히는 것이 전부라(판은 임베드이고, 임베드 안에서는 이모지가 글자 크기다)
진짜 카드처럼 안 그리고 키캡처럼 만든다. 무늬는 **네 가지 색**으로 나눈다 —
빨강·검정 둘로는 작을 때 ♥♦ 과 ♠♣ 가 구분이 안 된다.

봇은 부팅할 때 **앱 이모지를 먼저** 찾고 없으면 서버 이모지를 본다. 둘 다 없으면
주사위는 키캡 숫자, 카드는 `**A**♠️` 로 그린다 — 아무것도 안 올려도 게임은 돈다.
